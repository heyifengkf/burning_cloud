# 朝霞 / 晚霞预测算法设计

> 基于地面气象观测（总云量、高/中/低云、温度、湿度、降水、风向、能见度）判断是否出现朝霞或晚霞，并给出**出现概率 P** 与**燃烧程度 I**。
>
> 本文档只给出算法设计（公式、阈值、校准协议），不含具体代码实现。

## 1. 问题拆解

"会不会出现"和"烧得怎么样"是两个不同的目标，必须**分开建模**。

| 输出 | 含义 | 决定性因素 |
|---|---|---|
| **P（出现）** | 有没有霞（二值 → 概率） | 地平线光路是否通畅、是否有"画布"云 |
| **I（燃烧程度）** | 颜色有多艳、范围多大、持续多久 | 云的光学厚度、气溶胶、被照亮的云量 |

两者相关但非共线：

- 可以"有霞但很淡"（P 高，I 低）；
- 也可以"理论上该烧但被低云挡死"（P ≈ 0）。

因此采用**先门控、再打分、后校准**的结构，最终向用户展示 `(P, I_eff)` 二元组：
`P` 回答"会不会"，`I_eff` 回答"烧得好不好"。

## 2. 数据需求

### 2.1 现有观测

总云量、高云、低云、中云、温度、湿度、降水、风向、能见度。

### 2.2 缺失但必需的输入

上述 9 个量都是**标量**，而霞是**方向性 + 垂直分层**现象，必须补充：

1. **日出 / 日落时刻的太阳方位角与高度角**
   （由经纬度 + 日期用天文公式计算，NOAA 算法即可）
   - 晚霞关注**西边**方位扇区，朝霞关注**东边**扇区。
2. **地平线遮挡 / 光路洁净度**
   太阳方位 ±30°、仰角 0–10° 扇区内是否存在低云、山体、降水。
   这是**最关键的变量**，重要性远高于总云量。

> 若拿不到"方位扇区云量"，退化用全天空总量作为代理，但误差会明显变大。
> 建议至少使用数值预报的分层云量，或卫星云图 / 全景天空相机做分扇区统计。

## 3. 记号与预处理

### 3.1 输入变量（归一化后）

| 符号 | 含义 | 单位 / 范围 | 归一化 |
|---|---|---|---|
| `c_t` | 总云量 | 0–1 | /100 |
| `c_h`, `c_m`, `c_l` | 高 / 中 / 低云量 | 0–1 | /100 |
| `T` | 气温 | °C | — |
| `RH` | 相对湿度 | 0–1 | /100 |
| `P` | 降水率 | mm/h | — |
| `WD` | 风向（风的来向） | 0–360° | — |
| `VIS` | 能见度 | km | — |
| `φ`, `λ` | 纬度、经度 | deg | — |
| `t` | 时刻 | — | — |

### 3.2 基础算子

```text
clamp(x, a, b)      = min(max(x, a), b)
ramp(x; x0, x1)     = clamp((x − x0)/(x1 − x0), 0, 1)        # 要求 x1 > x0
fall(x; x0, x1)     = 1 − ramp(x; x0, x1)                    # x≤x0 → 1，x≥x1 → 0
bell(x; μ, σ)       = exp( −((x − μ)/σ)² )
bell_asym(x; μ, σ₋, σ₊) = exp( −((x−μ)/σ)² ),  σ = σ₋ if x<μ else σ₊
```

`ramp` / `fall` 是**分段线性**，边界处 C⁰ 连续但导数不连续——对本用途足够，且便于解释。

### 3.3 派生量

**(a) 太阳方位角 `θ_s` 与高度角 `h_s`**
（天文公式：NOAA 算法，输入 φ, λ, t）

**(b) 地平线扇区与扇区云量**
（可选的天空网格 `{θ_i, c_i}`，θ_i 为方位角）

```text
w_i = exp( −((θ_i − θ_s)/σ_θ)² ),   σ_θ = 25° ,  |θ_i − θ_s| ≤ 60°  (超出置 0)
c_X^sec = Σ_i c_X,i · w_i / Σ_i w_i        X ∈ {h, m, l, t}
```

若无方向数据，退化：

```text
c_X^sec ≈ c_X · a_X ,   a_X = 1.0（默认各向同性；可按站点气候学调整）
```

> ⚠️ 各向同性近似是本算法最大的误差源，实测 A/B 中它可让 Brier 恶化 0.05–0.10。

**(c) 露点差**
（需由 T、RH 反算露点）`Td = T − (100 − RH·100)/5`（Magnus 近似，或精确公式）；
`SPREAD = T − Td`

**(d) 云层几何高度**（层中值，km）

```text
z_h = 10 ,  z_m = 4 ,  z_l = 1.5
```

**(e) 照亮高度门限**
给定太阳下沉角 `d = −h_s`（度），能被照亮的云底最低高度：

```text
z_min(d) = R⊕ · (1/cos(d) − 1) ≈ R⊕ · d²/2      R⊕ = 6371 km, d 用弧度
```

参考值：`d=1° → 0.97 km`；`d=2° → 3.9 km`；`d=3° → 8.7 km`；`d=6° → 35 km`（即无云可照，霞结束）。

**(f) 云层被照亮指示函数**（在参考下沉角 `d_ref` 处评估）

```text
L_X = 1  if z_X ≥ z_min(d_ref)  else 0
```

> 建议 `d_ref = 2.0°`（"金色时刻"），此时只有 >3.9 km 的云被照亮，
> 物理上自然让**卷云 / 卷层云成为主角**。

## 4. 第一层：门控函数（乘性硬约束）

下列因子全部 ∈ (0, 1]，**相乘**使用。
设计原则：**光路被挡 → 整体概率归零**，所以用乘法，而不是加法扣分。

```text
G_precip  = (1 − 0.95·ramp(P_now;  0.0, 0.5)) · (1 − 0.50·ramp(P_1h; 0.0, 2.0))
G_lowcloud= 1 − 0.95·ramp(c_l^sec; 0.30, 0.70)
G_overcast= 1 − 0.85·ramp(OPAQUE;  0.70, 0.90)    其中 OPAQUE = c_l + 0.6·c_m
G_vis     = 0.30 + 0.70·ramp(VIS;  5, 20)
G_dew     = 1 − 0.60·fall(SPREAD;  0.5, 3.0)
```

### 4.1 门控阈值速查

| 因子 | 无惩罚 | 开始衰减 | 触底 | 触底值 |
|---|---|---|---|---|
| `P_now` | 0 | 0 – 0.5 mm/h | ≥0.5 mm/h | 0.05 |
| `P_1h` | 0 | 0 – 2 mm/h | ≥2 mm/h | 0.50 |
| `c_l^sec` | ≤30% | 30–70% | ≥70% | 0.05 |
| `OPAQUE` | ≤70% | 70–90% | ≥90% | 0.15 |
| `VIS` | ≥20 km | 5–20 km | ≤5 km | 0.30 |
| `SPREAD` | ≥3.0 °C | 0.5–3.0 | ≤0.5 °C | 0.40 |

### 4.2 组合门控

```text
G = G_precip · G_lowcloud · G_overcast · G_vis · G_dew
```

> 注意 `P_1h`（过去 1 小时降水）用 0.5 的弱惩罚：
> **雷雨后转晴是加分场景**，不该被一票否决。

## 5. 第二层：画布软评分（钟形响应）

"画布"指天空中有多少可被点燃的云。关系是**钟形**：
太少没东西可烧，太多糊成灰。

```text
S_canvas = Σ_X w_X · bell(c_X^sec; μ_X, σ_X)          X ∈ {h, m, l, t}
```

| 分量 | 权重 `w_X` | 峰值 `μ_X` | 展宽 `σ_X` | 有效区间（bell≥0.5） |
|---|---|---|---|---|
| 高云 `c_h^sec` | **0.45** | 0.40 | 0.28 | 21%–59% |
| 中云 `c_m^sec` | **0.30** | 0.30 | 0.22 | 15%–45% |
| 低云 `c_l^sec` | **0.10** | 0.10 | 0.15 | 0–21% |
| 总云 `c_t` | **0.15** | 0.50 | 0.28 | 28%–72% |

`Σw_X = 1.0`，故 `S_canvas ∈ [0,1]`。

> 低云给 0.10 的**正向**权重是刻意的：少量碎积云能提供明暗层次和地平线剪影，
> 过量才由 `G_lowcloud` 杀掉。

## 6. 第二层：辅助软评分

```text
S_vis   = ramp(VIS; 10, 40)                              # 空气洁净 → 颜色饱和
S_hum   = 1 − 0.50·ramp(RH; 70, 95)                      # 近地水汽 → 霾/雾
S_trend = clamp(0.50 − 2.0·Δc_t, 0, 1)                   # Δc_t = c_t(now) − c_t(now−60min)
S_wind  = 0.50 + 0.50·cos( (WD + 180°) − θ_s )           # 高云平流是否移入太阳扇区
```

| 分量 | 最优条件 | 最差条件 | 备注 |
|---|---|---|---|
| `S_vis` | ≥40 km → 1.0 | ≤10 km → 0 | 与 `G_vis` 分工：G 管光路，S 管成色 |
| `S_hum` | RH ≤70% → 1.0 | RH ≥95% → 0.5 | 权重低，避免与 `G_dew` 重复计分 |
| `S_trend` | 1h 内云量降 25% → 1.0 | 升 25% → 0 | 描述"越来越好还是越来越糟" |
| `S_wind` | 气流吹向太阳 → 1.0 | 吹离 → 0 | **实验性**，建议权重 ≤0.06，或先置 0 |

### 6.1 基底评分

```text
S_base = 0.62·S_canvas + 0.14·S_vis + 0.08·S_hum + 0.10·S_trend + 0.06·S_wind
         └ 权重和 = 1.00，S_base ∈ [0,1]
```

## 7. 组合与概率映射

### 7.1 总分

```text
Score = G · S_base ∈ [0, 1]
```

### 7.2 概率校准（Platt scaling）

**不要直接把 `Score` 当概率**。用 sigmoid 拟合：

```text
z = k · (Score − θ)
P = 1 / (1 + exp(−z))

初始值：k = 6.0 ,  θ = 0.45
```

等价地，`Score = θ` 处 P = 0.5，
`Score` 每变化 `1/k ≈ 0.167` 使几率变化 e 倍。

有 ≥500 条标注后改用 **isotonic regression**（单调、无形状假设）；
样本少时保持在 Platt。

### 7.3 概率分级

| `P` | 表述 |
|---|---|
| ≥0.80 | 极可能出现 |
| 0.60–0.80 | 很可能 |
| 0.40–0.60 | 有可能 |
| 0.20–0.40 | 概率较低 |
| <0.20 | 基本不会 |

## 8. 强度模型（燃烧程度 I）

强度**独立建模**，重点刻画"光学厚度钟形响应"这一非线性。

### 8.1 光学厚度代理

```text
τ̂ = 0.10 + 0.25·c_h + 1.20·c_m + 5.00·c_l
```

（`0.10` 为晴空分子散射本底）

对应关系：卷云 τ≈0.1–0.3｜卷层云 0.3–1｜高积云 0.5–2｜高层云 1–3｜层云 3–10。

> 若上游有 NWP 云光学厚度产品，**直接替换 τ̂**，这是强度模型提升最大的一处。

### 8.2 四个子评分

**S_thick —— 钟形，最反直觉的一项**

```text
S_thick = bell_asym(τ̂; μ = 0.90, σ₋ = 0.45, σ₊ = 1.50)
```

| τ̂ | S_thick | 现象 |
|---|---|---|
| 0.10 | 0.09 | 太薄，几乎看不见 |
| 0.45 | 0.60 | 淡 |
| **0.90** | **1.00** | 最艳的红/橙/品红 |
| 1.80 | 0.70 | 偏灰 |
| 3.00 | 0.16 | 一片灰白 |
| ≥5 | <0.02 | 完全烧不起来 |

**S_lit —— 被照亮的范围**

```text
c_lit = Σ_X c_X^sec · L_X           # L_X 取 d_ref = 2.0° 的照亮指示函数
S_lit = ramp(c_lit; 0.05, 0.55)
```

**S_color —— 颜色纯净度**

```text
S_color = 0.60·ramp(VIS; 10, 40) + 0.40·(1 − ramp(RH; 60, 95))
```

**S_dur —— 持续时长**

```text
z_top = max{ z_X : c_X^sec ≥ 0.05 }                    # 最高的可察觉云层
T_glow = 2 · h_c(z_top) / |dh_s/dt|                    # 分钟；|dh_s/dt| ≈ 0.25 °/min（中纬）
       h_c(z) = arccos( R⊕/(R⊕ + z) )                  # 弧度，转度
S_dur = ramp(T_glow; 5, 30)
```

| `z_top` | `h_c` | `T_glow` | `S_dur` |
|---|---|---|---|
| 1.5 km（低云） | 1.24° | 10 min | 0.20 |
| 4 km（中云） | 2.03° | 16 min | 0.45 |
| 10 km（高云） | 3.21° | 26 min | 0.83 |

### 8.3 强度合成

**加权几何平均**（任一项归零则整体归零，符合物理）：

```text
I = 5 · S_thick^0.30 · S_lit^0.30 · S_color^0.25 · S_dur^0.15
```

指数和为 1.0，故 `I ∈ [0, 5]`。

| `I` | 级别 | 描述 |
|---|---|---|
| 0–0.5 | 0 | 无霞 |
| 0.5–1.5 | 1 | 微弱（一抹淡黄/淡粉） |
| 1.5–2.5 | 2 | 一般（局部橙红） |
| 2.5–3.5 | 3 | 明显（大面积橙红，轮廓清晰） |
| 3.5–4.5 | 4 | 强烈（红紫交织，层次丰富） |
| 4.5–5.0 | 5 | 爆烧（整片通红发紫，持续久） |

### 8.4 展示用有效强度

```text
I_eff = G · I        # 门控失败时，即使 I 很高也不该报"爆烧"
```

> 注意 **P 高不代表 I 高**：
> 晴朗少云的黄昏 P 可能中等但 I 也偏低；
> 而薄卷云 + 空气干净时 P 和 I 会同时拉满。

## 9. 全变量阈值汇总表

| 变量 | 关键断点 | 作用位置 | 方向 |
|---|---|---|---|
| `c_t` 总云量 | 28% / 50% / 72% | `S_canvas` | 钟形 |
| `c_h^sec` 高云 | 21% / 40% / 59% | `S_canvas`（w=0.45） | 钟形 |
| `c_m^sec` 中云 | 15% / 30% / 45% | `S_canvas`（w=0.30） | 钟形 |
| `c_l^sec` 低云 | 10% / 21%（软）· 30% / 70%（硬） | `S_canvas` / `G_lowcloud` | 钟形 / 递减 |
| `OPAQUE` | 70% / 90% | `G_overcast` | 递减 |
| `VIS` | 5 / 20（门控）· 10 / 40（成色） | `G_vis` / `S_vis` / `S_color` | 递增 |
| `SPREAD` | 0.5 / 3.0 °C | `G_dew` | 递增 |
| `RH` | 60 / 95（成色）· 70 / 95（水汽） | `S_color` / `S_hum` | 递减 |
| `P_now` | 0 / 0.5 mm/h | `G_precip` | 递减 |
| `P_1h` | 0 / 2 mm/h | `G_precip` | 递减 |
| `∆c_t` (1h) | −0.25 / +0.25 | `S_trend` | 递减 |
| `WD` vs `θ_s` | cos ∈ [−1, 1] | `S_wind` | 方向余弦 |
| `τ̂` | 0.2 / 0.9 / 3.0 | `S_thick` | 非对称钟形 |
| `z_top` | 1.5 / 10 km | `S_dur` | 递增 |
| `c_lit` | 5% / 55% | `S_lit` | 递增 |

> **温度 `T` 未出现在任何公式中**——它与霞的相关性是通过 `SPREAD` 和季节上下文间接体现的，
> 直接给权重只会引入噪声。

## 10. 校准与验证协议

1. **标签来源**（没有标签就只能是专家规则，效果有限）：
   - 天空相机 / 网络摄像头延时摄影 → 用色彩饱和度 + 红/蓝比值自动打标；
   - 众包打分（用户 App 上报"几级霞"）；
   - 已有公开日落评分产品做弱标签。
2. **模型选择路线**：
   - 起步：物理规则 + 手工权重（可解释、无需数据）；
   - 有几百条标签后：逻辑回归（保持可解释、自带概率校准）；
   - 上千条后：GBDT（XGBoost / LightGBM）吃交互项，再用 SHAP 回看物理合理性。
3. **单调性自检**：对每个输入做偏导符号检查，确认响应方向符合物理直觉；
   `bell` 类特征需断言峰值位置。
4. **超参清单（共约 40 个可调量）**：
   4 组门控阈值、4 个 `w_X`+`μ_X`+`σ_X`、5 个外层权重、`k`/`θ`、强度侧 4 组阈值与 4 个指数。
   建议先**冻结门控阈值**（物理约束，不应过拟合），只调 `μ/σ/w` 与 `k/θ`。
5. **必须做地点校准**：海平面 vs 山区、城市霾 vs 高原，地平线剖面和阈值差异很大；
   建议至少设 `θ_site` 一项偏置按站点/区域分别拟合。
6. **评估指标**：概率用 **Brier score + 可靠性曲线**（不看准确率）；
   强度用分级准确率或序数回归的 MAE。
7. **消融对照**：`τ̂` 换成真实光学厚度、`c^sec` 换成各向同性——
   这两项单独做消融，量化各自增益。
8. **保留可解释性**：每个得分都要能回到
   "因为西边低云 15%、能见度 28km、卷云 40%" 这样的解释，用户才信。

## 11. 已知局限

- `τ̂` 是用云量**代理**厚度，两者并非一一对应；
  薄而广的卷云会被高估，厚而窄的积云会被低估。
- `S_wind` 的物理依据最弱（高云平流方向通常无法从地面风向推断），建议初期置 0 权重。
- `d_ref = 2°` 是固定评估点；若想要更完整的"烧的过程"，
  可对 `d ∈ [0°, 4°]` 以 0.5° 步长采样 `S_lit` 与 `S_thick`，取时间积分作为增强版的 `I`。
- 门控与软评分之间存在**耦合**（`c_l` 同时进 `G_lowcloud` 和 `S_canvas`），
  这是刻意的双重约束；若校准发现过度惩罚，可把 `S_canvas` 中的 `c_l` 权重降到 0.05 或移除。

## 12. 落地优先级建议

1. **先补太阳方位/高度 + 地平线扇区云量**——这一步的收益比换任何模型都大。
2. 用**三层结构**（门控 → 钟形打分 → 概率校准）快速跑通，拿到基线。
3. 同步开始**收集标签**（相机或众包），否则永远停在专家规则。
4. 强度模型**独立训练**，重点刻画"光学厚度钟形响应"这一非线性。
5. 保留**可解释性**，让每个预测结果都能追溯到具体气象要素。
